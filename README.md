# TypeScript Problem Solving & Technical Blogs

## Description
This repository contains solutions to various TypeScript coding problems and two technical blog posts discussing important TypeScript concepts.

## Repository Structure
* `solutions.ts`: Contains all the TypeScript coding problem solutions (1 to 7) in a single file.
* `blog-1.md`: A technical blog post on why `any` is a type safety hole and why `unknown` is the safer choice.
* `blog-2.md`: A technical blog post on how `Pick` and `Omit` utility types prevent code duplication and keep TypeScript code DRY.

## How to Run the Code
To execute the `solutions.ts` file, ensure you have Node.js installed, then use `tsx` directly from your terminal:

```bash
npx tsx solutions.ts
```

**Problems Solved**
1. Filtering even numbers from an array.
2. Reversing a string.
3. Using Type Guards with Union Types.
4. Using Generics to get object properties safely.
5. Modifying object interfaces and adding properties.
6. Object-Oriented Programming (OOP) with Classes and Inheritance.
7. Finding the intersection of two arrays.
